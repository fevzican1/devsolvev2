# DevSolve — Free, Privacy-First Developer Tools & Guides

**Website: [https://devsolvev2.com](https://devsolvev2.com)**

DevSolve is a collection of free, browser-based developer tools and in-depth
engineering guides. **All processing happens locally in your browser — your
data never leaves your device.** No signup, no uploads, no tracking.

## Why DevSolve?

- **Privacy-first** — 100% local processing, zero data collection.
- **Instant** — no server round-trips; results as you type.
- **Works offline** — once loaded, the tools run without a connection.

## Tech stack

- [Next.js](https://nextjs.org/) (static export) + React + TypeScript
- Tailwind CSS
- Deployed on Cloudflare Pages, with on-demand edge-rendered programmatic
  content served from the global CDN.
